Background

There are many graphic systems in R for making plots and figures. These include “base R graphics” like the plot() and add-on packages like ggplot2.

Let’s compare how we make a simple graph with these two systems:

We can use the in-built cars dataset:

head(cars)
  speed dist
1     4    2
2     4   10
3     7    4
4     7   22
5     8   16
6     9   10

A base R plot:

plot(cars)

Now for ggplot2. Before I can use ggplot2 I need to install it on my computer. To do this we can use the function install.packages("ggplot2")

N.B We never run an install.packages() in our quarto doc (we can run it in our R console) as it would re-install the package every time I render my document.

Once installed we still need to load it up the package into our R session. We do this with a library() call

library(ggplot2)
ggplot(cars)

Every ggplot needs at least 3 inputs:

  • the data (a data.frame of the stuff we want to plot)
  • the aesthetics (how the data maps to the plot),
  • the geom layer (how you want the plot drawn, points, lines, etc.)
ggplot(cars) + 
  aes(x=speed, y=dist) + 
  geom_point()

Let’s add some features (more layers)

Let’s add a trend line that shows the relationship between speed and distance

ggplot(cars) + 
  aes(x=speed, y=dist) + 
  geom_point()
ggplot(cars) + 
  aes(x=speed, y=dist) + 
  geom_point() +
  geom_smooth(method="lm", se=FALSE) + 
  theme_bw() + 
  labs(x="Speed MPH", 
       y="Stopping Distance (ft)" , 
       title="Stopping distance of some old cars")
`geom_smooth()` using formula = 'y ~ x'

Let’s make our first plot of gdpPercap vs lifeExp :

ggplot(gapminder) + 
  aes(x=gdpPercap, y=lifeExp) + 
  geom_point()

Adding transparency to the points.

ggplot(gapminder) + 
  aes(x=gdpPercap, y=lifeExp) + 
  geom_point(alpha=0.25)

Adding color to the different continents.

ggplot(gapminder) + 
  aes(x=gdpPercap, y=lifeExp, color=continent) + 
  geom_point(alpha=0.25)

One useful layer we can add to explore big datasets like this is called “facetting”

ggplot(gapminder) + 
  aes(x=gdpPercap, y=lifeExp, col=continent) + 
  geom_point() +
facet_wrap(~continent)
